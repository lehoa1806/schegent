# Artifact quality rubric

rubricVersion: 1

This rubric lists the qualities a reviewer judges when reading a Spec Kit specification, plan or task
list. They are judged by a person. No automated check scores this rubric. The evaluator in this directory
reads only the version line above, so that it can report it.

- **Clarity**: a reader who did not write the artifact can say what it asks for.
- **Testability**: each requirement can be checked by a stated observation.
- **Scope discipline**: the artifact asks for what the feature needs, and names what it leaves out.
- **Traceability**: each plan decision and each task points back to a requirement.
