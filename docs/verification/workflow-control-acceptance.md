## 3. Schema Compatibility, Preserved Hard Rules & Security/Privacy Impact

- **Schema Compatibility**:
  - `STATE_SCHEMA_VERSION` (`src/state/workspace-state.ts`) and `SCHEMA_VERSION = 4` (`src/ui/sidebar/snapshot.ts`) are unchanged.
  - All new contracts (`DecisionResultRecord`, `TypedCondition`, `CandidateBlock`, `WorkflowNodeControl`, `ControlLedgerRecord`, `RecoveryEnvelope`, `AvailabilityWatchState`, `ControlCommandEnvelope`, `ConnectedRepeatNodeProjection`, `ConnectedForEachNodeProjection`, `ForEachCollectionSnapshot`, `ForEachResultIndex`) carry `version: 1` and are strictly additive on existing Workflow definitions and IPC snapshots.
  - Regenerated contract schemas (`contracts/schemas/*.schema.json`) and webview type mirrors pass `npm run contracts:check` with zero diff.
- **Preserved Hard Rules (`docs/hard-rules.md`)**:
  - **Audit & Redaction**: Every recovery summary, terminal excerpt, availability diagnostics string, and control audit event passes through `redactForAudit(...)` before persistence or IPC emission; metadata-only audit by default is preserved.
  - **Narrow File & Directory Modes**: All files under `.schegent/control/`, `.schegent/checkpoints/`, and `.schegent/results/` are written atomically via temp-and-rename with mode `0600` inside `0700` directories.
  - **Window Primacy & Workspace Trust**: `ControlCommandService` and the IPC router refuse mutating control actions (`pause`, `resume`, `cancel`, `retry-candidate`, `skip-candidate`, `renew-monitoring`) when `isWorkspaceTrusted` or `isPrimaryWindow` is false.
  - **Headless Isolation & Bounded Queues**: All availability probes use read-only adapter status checks (`<= 5,000 ms` timeout) and never spawn synthetic prompt-charging CLI turns.

## 4. Measured Limits (`D1`) & Accessibility Rule Coverage

- **Measured Limits (`D1`)**:
  - `CandidateBlock.candidates`: `2..10` unique candidates per block.
  - `CandidateSpec.maxAttempts`: `1..10` attempts per candidate.
  - `CandidateBlock.maxWaitSeconds`: `60..604,800` seconds (`1 min` to `7 days`).
  - `RepeatControl.maxIterations`: `1..25` passes.
  - `ForEachControl.maxItems`: `1..100` items (`<= 262,144` UTF-8 bytes collection snapshot).
  - `RecoveryEnvelope`: `<= 16,384` UTF-8 bytes total (`<= 2,048` bytes summary, `<= 4,096` bytes terminal excerpt, `<= 200` changed paths).
- **Accessibility & Visual Coverage**:
  - Playwright visual suite (`tests/visual/workflow-control.visual.spec.ts`) and axe-core accessibility suite (`tests/a11y/workflow-control.a11y.spec.ts`) verify `CandidateBlockEditor`, `CandidateBlockInspector`, `repeat-node-projection-*`, and `foreach-node-projection-*` across `light`, `dark`, and `high-contrast` themes with zero inline `style` attributes and zero violations across `['wcag2a', 'wcag2aa', 'wcag21a', 'wcag21aa']`.
